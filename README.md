# UNES — University Website

> **Institutional website developed with HTML5 as a front-end fundamentals project.**

UNES is a fictional university website created to practice the fundamental concepts of web development and the structure of a multi-page website.

The project represents a simple institutional website containing a home page, information about the university and a contact page.

## 📌 Project Overview

The website was developed with a focus on understanding the fundamentals of **HTML document structure, page navigation, forms, images and content organization**.

### Main sections

* 🏠 **Home** — University presentation and main information
* 🏛️ **Who We Are** — Institutional information and advantages for students
* 📩 **Contact** — Contact form interface

## 🛠️ Technologies

* **HTML5**
* Basic web forms
* HTML tables for page layout
* Local image assets
* Internal page navigation

No external frameworks, libraries or dependencies are required.

## 🎯 Learning Objectives

This project was created to reinforce the following front-end concepts:

* HTML document structure
* Headings, paragraphs and text formatting
* Links and navigation between pages
* Images and local assets
* Ordered lists
* HTML forms and input fields
* Basic page organization
* Structuring a small multi-page website

## 🚀 Running the Project

The project has no dependencies or build process.

Clone the repository:

```bash
git clone https://github.com/Blxck-2001/UNES---University-Website.git
```

Open `index.html` in a web browser to run the website locally.

The project can also be deployed through a static hosting service such as GitHub Pages.
